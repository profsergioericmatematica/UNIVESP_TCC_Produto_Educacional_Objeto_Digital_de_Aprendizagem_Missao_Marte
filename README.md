## 📋 Sobre o Projeto
O **Missão Marte** utiliza a narrativa de exploração espacial para contextualizar o estudo da **Função de 1º Grau (Função Afim)**. O jogo foi projetado, por alunos do Curso de Graduação de Licenciatura em Matemática da Universidade Virtual do Estado de São Paulo (UNIVESP), para alunos do 1º ano do Ensino Médio, integrando os desafios matemáticos à sobrevivência em uma base em Marte.

### 🎯 Objetivo Diagnóstico (Foco do TCC)
Diferente de jogos educativos puramente lúdicos, este software funciona como uma **ferramenta de avaliação diagnóstica**. Ele monitora:
- O percurso cognitivo do aluno.
- A quantidade de tentativas necessárias em cada nível.
- Erros específicos de interpretação (coeficientes, raízes e sistemas).

Ao final da missão, o sistema gera um **Relatório Diagnóstico (.TXT)** que o aluno deve descarregar e enviar ao professor. Este log permite uma intervenção pedagógica precisa e baseada em dados reais de aprendizagem.

## 🕹️ Os 5 Níveis da Missão
1. **Módulo de Combustível:** Interpretação de tabelas e lei de formação $f(x) = ax + b$.
2. **Painéis Solares:** Manipulação dinâmica de coeficientes e inclinação da reta.
3. **Sinal de Satélite:** Tradução da representação gráfica para a algébrica.
4. **Gerador de Oxigénio:** Identificação do zero da função (raiz).
5. **Rotas de Colisão:** Resolução de sistemas lineares (intersecção de retas).

---

## 🛠️ Instruções Técnicas para o Júri
Para garantir o funcionamento pleno das funcionalidades de relatório e gráficos:
1. **Navegador:** Recomendamos o uso do Google Chrome ou Microsoft Edge atualizados.
2. **Dispositivos:** O jogo é responsivo e pode ser utilizado em computadores, tablets ou smartphones.
3. **Relatório Final:** Após completar o 5º nível, clique no botão **"Baixar Relatório de Missão"**. O arquivo será gerado localmente, como um arquivo de texto, sem necessidade de base de dados externa, garantindo a privacidade dos dados e permitindo a exportação do desempenho acadêmico via tecnologia `Blob API` [¹](#nota1), o que assegura a portabilidade dos dados diagnósticos.
